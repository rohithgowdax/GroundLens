# Augmentations

In this folder, we provide illustrations of different augmentations experimented with to test generalization. Each image shows an example of an augmented document. We list each augmentation here with their respective file: 

- Original (`original.png`)
- Noise & Blur (`noise_and_blur.png`)
- Compression & Resampling (`compression_and_resampling.png`)
- Photometric Jitter (`photometric_jitter.png`)
- Print Artifacts (`print_artifacts.png`)
